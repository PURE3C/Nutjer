# 📅 ว่างวันไหน?

เว็บเช็ควันว่างของแกงค์ ใช้ง่ายสุดๆ สำหรับเพื่อนขี้เกียจ:

1. เปิดลิงก์ → แตะชื่อตัวเอง (ครั้งเดียว เว็บจำให้)
2. เลือกนัด (เช่น เที่ยวงานวัด, เตะบอล) หรือสร้างนัดใหม่
3. แตะวันที่ว่างในปฏิทิน → บันทึกอัตโนมัติ
4. ดู "วันที่ว่างตรงกันเยอะสุด" ได้เลย

แต่ละนัดมีปฏิทินวันว่างแยกกัน มีปุ่มลัด "ว่างทุก ส.-อา. เดือนนี้" และรายชื่อคนที่ยังไม่กรอก

ถ้ายังไม่ได้ตั้งค่า Firebase เว็บจะเปิดใน **โหมดทดลอง** (เก็บข้อมูลไว้แค่ในเครื่องตัวเอง) ใช้ลองเล่นได้

---

## ตั้งค่า (ทำครั้งเดียว ~5 นาที)

### 1. สร้างฐานข้อมูล Firebase (ฟรี)

1. ไปที่ <https://console.firebase.google.com> → **Add project / สร้างโปรเจกต์** (ปิด Google Analytics ได้)
2. เมนูซ้าย **Build → Realtime Database → Create Database**
   - เลือก location **Singapore (asia-southeast1)**
   - เลือก **Start in locked mode**
3. ไปแท็บ **Rules** → ลบของเดิม แล้ววางเนื้อหาจากไฟล์ [`database.rules.json`](database.rules.json) → **Publish**
4. กลับไปหน้า **Project settings** (รูปเฟือง) → เลื่อนลงไป **Your apps** → กดไอคอน **`</>`** (Web) → ตั้งชื่ออะไรก็ได้ → **Register app**
5. จะได้ก้อน `firebaseConfig = { ... }` → คัดลอกค่าไปใส่ใน [`firebase-config.js`](firebase-config.js)
   (ต้องมี `databaseURL` ด้วย ถ้าไม่มี ให้คัดลอก URL จากหน้า Realtime Database มาใส่เอง)
6. แก้ `groupName` ใน `firebase-config.js` เป็นชื่อแกงค์ได้

> ค่า `apiKey` ของ Firebase ไม่ใช่ความลับ ใส่ในโค้ดสาธารณะได้ (Firebase ออกแบบมาแบบนี้)
> แต่ใครที่มีลิงก์เว็บจะเข้ามาเพิ่ม/แก้วันว่างได้ เหมาะกับกลุ่มเพื่อน ไม่ควรใช้เก็บข้อมูลสำคัญ

### 2. เปิดเว็บด้วย GitHub Pages

1. รวมโค้ดเข้า branch `main`
2. ใน GitHub repo → **Settings → Pages**
3. **Source: Deploy from a branch** → Branch **`main`** / folder **`/ (root)`** → **Save**
4. รอ 1–2 นาที จะได้ลิงก์ประมาณ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` → ส่งให้เพื่อนในกลุ่ม LINE

### เพิ่ม/ลบชื่อเพื่อน

- **เพิ่ม:** ใครยังไม่มีชื่อ พิมพ์ชื่อตัวเองที่หน้าแรกได้เลย (หรือคุณเปิดเว็บแล้วเพิ่มชื่อให้ทุกคนไว้ก่อนก็ได้ กด "ไม่ใช่ ...?" เพื่อสลับกลับ)
- **ลบ:** Firebase Console → Realtime Database → ลบรายการใต้ `members/<id>`

## ทดลองในเครื่อง

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## ไฟล์

| ไฟล์ | ทำอะไร |
| --- | --- |
| `index.html` | หน้าเว็บ |
| `app.js` | ตัวโปรแกรมทั้งหมด |
| `style.css` | หน้าตา |
| `firebase-config.js` | ค่าตั้ง Firebase + ชื่อแกงค์ |
| `database.rules.json` | กฎความปลอดภัยของฐานข้อมูล (วางใน Firebase Console) |
